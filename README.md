# ARound — contenuti delle città

Questo repository contiene **solo i dati** che l'app ARound scarica: i JSON
delle città e le immagini. Viene riempito automaticamente dal repository
dell'app, che è privato.

Non modificare niente a mano: la prossima pubblicazione sovrascrive tutto.

## Cosa c'è dentro

    data/index.json              elenco delle città, un file solo per tutte le lingue
    data/cities/<id>.<lang>.json contenuto completo di una città in una lingua
    data/images/                 le foto, e crediti.json con la loro provenienza

## Licenza

I contenuti — testi, selezione e ordine dei luoghi — sono di chi li ha scritti,
e non sono rilasciati sotto alcuna licenza d'uso: sono qui perché un'app li
scarica da un browser, non perché siano riutilizzabili.

Le fotografie provengono da terzi: `data/images/crediti.json` registra per ogni
file l'indirizzo da cui è stato scaricato.
